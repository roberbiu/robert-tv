## 构建基线

使用项目 Gradle Wrapper 7.5、AGP 7.2.2、Android SDK 33，优先 JDK 17。Android SDK 路径通过本机 local.properties 配置，该文件不进入仓库。不要修改系统级环境变量来绕过项目配置问题。

PowerShell 调试构建：

~~~powershell
Set-Location -LiteralPath "C:/coding/myPro/robert-tv"
& "./gradlew.bat" :app:assembleJavaDebug --stacktrace
~~~

上游 Java flavor 同时包含 armeabi-v7a、arm64-v8a 并禁用 ABI splits，适合作为单 APK 目标。发布目标为：

~~~powershell
& "./gradlew.bat" :app:assembleJavaRelease --stacktrace
~~~

发布命令不表示现有工程已具备私有签名配置；必须先配置项目签名并核验最终 APK。不要使用上游公开测试签名。

项目本机已建立独立签名，配置方式见[签名说明](signing.md)。普通 Debug 使用 `.debug` 包名后缀；可用 `-ProbertDebugSuffix=.debug.fixture` 隔离回归安装，避免覆盖其他测试应用。

本地原创夹具可通过 `-ProbertFixtureAssets=包含robert/catalog.json的资源目录` 仅编入 Debug。以 `.debug.fixture` 开头的调试包将指定的 `127.0.0.1.nip.io` 测试域名映射到模拟器本机，并配合 `adb reverse`；普通调试包与发布包不改变 DNS。发布变体不读取夹具资源目录。

不要直接执行全部 assembleRelease：Python 变体还涉及 pyramid，上游该模块含机器相关 Python 路径及额外 Build Tools 要求。首版不因未使用的变体引入无关安装与迁移。

上游 CI 会重新获取上游源码并使用公开测试签名，不能原样用于本项目发布。项目 CI 应构建当前仓库的固定代码和指定 Java 变体，不自动跟随上游或清理无关历史。

## 验收矩阵

| 场景 | 检查点 |
| --- | --- |
| 首次安装 | 不导入源、不填接口或字幕凭据、不配置服务器即可进入默认内容流程 |
| 遥控操作 | 搜索、详情、选集、播放、暂停、快进、返回无触控依赖 |
| 搜索故障 | 单来源超时或失败，其他来源结果仍能出现 |
| 结果正确性 | 同名不同年份、不同季集可区分；画质、字幕未知时明确标注 |
| 来源更新 | 下载失败、格式错误、适配器不匹配均不覆盖最近可用配置 |
| 真实播放 | 验证视频画面、声音及持续播放，不以 HTTP 状态或 HEAD 探活代替 |
| 播放替代 | 仅尝试匹配的同片同季集版本，不盲目沿用不同剪辑的进度 |
| 中文字幕 | 有中文优先；无中文尝试替代后明确标注，并允许播放 |
| 授权恢复 | 需要时扫码；重启保留有效会话；过期可重新授权；凭据流向经过核实 |
| 升级 | 使用相同发布签名，配置和历史迁移无需重新导入来源 |

片单记录至少包含：应用版本、源码提交、来源版本、片名、年份、季集、搜索命中、实播结果、字幕证据、授权要求、测试设备与脱敏失败信息。覆盖率使用真实样本分母，不预先填写达标数字。

## 交付与真机反馈

交付签名 APK、SHA-256、版本与兼容说明、安装升级说明、已知限制，以及对应源码提交。签名密钥、密码和其他秘密只保存在受控本地或经明确配置的秘密存储中，不进入 Git 历史或构建日志。

用户回家安装后，记录应用版本、电视系统、片名季集、复现步骤和脱敏错误信息。Cookie、token、个人观看记录与带凭据的播放地址不得进入公开反馈。问题修复后交付同签名版本，并补充验证记录。

ARM 原生库与 x86 模拟器可能存在 ABI 差异；模拟器安装或播放结果需注明环境。未在雷鸟上验证的项目不能标记为真机通过。
