## 可开发边界与需修正点

1. 可作为一个具体补充来源，覆盖国漫、日漫、欧美动画及动画电影；**不替代玩偶优先目标**，也不独自覆盖电视剧、综艺等全品类。
2. 用本项目统一站点接口／数据模型重写小适配器，复用现有Jsoup/Gson/HTTP能力；不需要为该站增加网盘模块或整套外部插件。站点层仅允许受控主机与实见路径，统一结果携带稳定来源ID。
3. 旧源码首页在逐分类请求过滤器时不断覆盖`doc`，最后可能拿末分类列表充首页；应分离首页和分类缓存、过滤器按需读取，不照搬这个行为。
4. 旧源码截取分类名称前两字、分类ID首字符，不宜推广为通用映射；使用实见导航与稳定类别映射。搜索关键词应明确UTF8编码。
5. 旧`categoryContent`没有给可靠总页数。需要解析实际分页链接或以有界下一页／空页结束，独立游标、去重与超时；不能伪造pagecount。此次未验证第2页。
6. `playerContent`返回iframe并要求解析；需要阶段3检查该页和最终媒体域名、播放头、声音、字幕、拖动、片中广告、TLS与失败回退。仅凭本报告不能将其标记为“无广告优质直连”或纳入正式优先源。

## 阶段判定

**该站已有具体、当前可解析的匿名元数据输入，可纳入架构中的补充源实现候选。** 公开搜索存在一次超时，必须保留超时隔离。媒体实播与广告／字幕质量是阶段3准入门槛，尚未通过；不需要把这些未测项隐藏成已验收，也不能据元数据成功建立1.0.0正式标签。
