# 1.0.0 导航、分类浏览与热播实现记录

本记录描述开发分工 C/D 的实现边界，不替代正式发布验收。全量 Gradle 构建、模拟器与雷鸟电视验证由主集成流程记录。

## 已接线

- 首页固定展示原有本机最近观看记录，保留 sourceKey、站内 id、年份和上次集数；空记录引导搜索，返回后刷新记录及卡片焦点。不再加载推荐。
- 一级导航按需求固定十项；四地区专区各含剧、电影、综艺、动漫。电影页提供纪录片子类。保留原有暗色布局、B 品牌资源和 HomeClock。
- 浏览和热播选片均进入统一搜索；传递标题及已有年份、类型、地区，不把榜单条目 ID 当站点播放 ID。无记录、来源暂不可用或空列表均有搜索入口。
- HomeActivity 不再等待全局 JAR 初始化，不调用外部 loadJar，不修改全局 homeSource，不自动启动通用局域网推送。

## 分类浏览约束

浏览捕获 SourceRegistry 的不可变快照；来源以优先级确定首次顺序，使用实际叶子类别名称和 ID。CMS 父类别和逗号多 ID 均不调用。国家专区只调用声明已验证服务端国家过滤的来源，并二次验证返回类型与完整国家 token。模糊欧美/日韩、缺失国家和类型不推断。

一次界面翻页冻结为目标 20 条、最多 6 次逻辑请求、18 秒总预算、单次最多 6 秒、串行请求（不超过架构最多 3 在途）。每轮先初始化最多 3 个来源，将余下预算用于分类页；实际来源×叶子有独立页码、失败退避和待消费条目缓冲，轮转起点在翻页间保留。单叶子最多 200 页；错误或连续不符合过滤结果不触发后台全库扫描。

当前用户入口未开放年份或站点排序筛选，因此 year 固定未指定，sort 固定来源默认顺序；切换内容类型、国家、来源 revision 或刷新会重新建立游标。已知年份电影、明确同季作品按规范身份去重，未知年份或未知季保留站内身份。

取消会终止匿名 HTTP 和 RequestContext。游标与已见集合仅在 UI 接收当前 generation/revision 的结果时提交；工作队列只保留最新一个待处理请求。原有列表收到失败或晚到结果时不会被旧查询覆盖。

## 热播约束

- 骨朵先读 configDay 的 DAILY.endDay，再读已经核实的六个原始子榜；电视剧和综艺分子榜展示，不造合成分。电影主榜明确为网络电影日榜，百度电影搜索热度只作额外参考。
- 红果仅解析指定 SSR 数据属性中已核实的 route/content 数组，保留作品必要字段；不执行脚本，不读取运行环境、内部地址、播放字段或简介。
- 各原始榜单独立 AtomicFile 缓存 6 小时；失败退避 15 分钟，手动刷新至少间隔 5 秒。空或错误保留上次有效结果。
- 匿名 HTTP 不带账号 Cookie、鉴权器或日志拦截器；单响应最多 1 MiB，同域重定向次数有界，拒绝私网目标。浏览不保留播放地址和详情正文。
- UI 展示真实榜单来源、指标、周期、源日期精度、实际更新时间是否提供、北京时间获取时刻和缓存/历史参考状态。七天前数据须用户主动选择查看。未知源日期按内容首次观察时间判断，同内容重复 GET 不续命；月日精度跨年也不重设内容年份。

## 已完成的局部验证

- Java 8 语法的独立 javac/JUnit：15 项结构测试，包含真实叶子与父 ID/逗号负例、国家完整 token/合拍、固定十项顺序、轮转及取消副本、未知作品身份、六骨朵类型合同、红果字段白名单、百度未知日期、旧榜与跨年同内容不续命。
- 离线回放本轮已经保存的公开原始响应：骨朵网络剧 20、电视剧 17、网络电影 20、网络综艺 20、电视综艺 18、动漫 20、百度电影 10、红果短剧 20，均可由当前解析器解析。测试仓库只存最小合成夹具，不复制原 HTML/完整榜单。
- 局部 git diff --check 通过；本分工未执行 Git 提交/推送、Gradle、模拟器操作、账号授权或媒体请求。
- 总时限追加验证：匿名 HTTP 每个 Call 按单调时钟剩余预算设置 OkHttp callTimeout，另保留定时 Call.cancel；重定向沿用同一总 deadline。浏览轮次 18 秒也使用单调时钟，不随北京时间或系统校时延长。两个回环慢滴流测试通过：每 25ms 写入一字节、readTimeout 为 2 秒，350ms 调用总时限中断读取；主动 Call.cancel 在 1.5 秒内解除正在读取的响应体。测试未请求公网，也未放宽生产私网目标校验。

## 快捷搜索作品身份提示追加接线

FastSearchActivity 读取 expected_year、expected_type、expected_area 和 picture。仅带这些作品上下文的入口展示顶部期待信息与参考封面；参考封面不会填入其他候选，也不作为版本相同的证据。每张候选卡显示真实年份、类型、地区，并分别标为字段一致、待核对或明确不同；缺失年份、未知类型、空地区及“欧美/日韩”等模糊地区均不能取得一致状态。

有作品上下文时，列表先按字段一致、待核对、明确不同排序，再沿用原来的均衡质量/字幕/授权排序。遥控器已聚焦卡片时保留原位置，不让晚到结果换片；不同或未知结果不会被删除，选片仍需用户点击。用户改为不同分词或手机输入另一词时，原作品上下文清除。普通未带 expected 参数的全局搜索继续原有逻辑。

传给既有详情页的自动后备候选，在此上下文内额外要求与用户实际选中结果的年份、类型和完整地区一致；未知季的连续内容也不进入这批自动后备，仍可手动选择。没有用期待年份替换候选实际年份。FastSearch 取消同时触发既有 SourceViewModel 的原生搜索取消，不改 ViewModel。

新增 8 项 ExpectedWorkIdentity 纯测试，覆盖同名不同年份/类型/国家/季、完整合拍及部分地区、未知期待信息、优先级、换词清上下文、参考图片限制和自动后备边界。连同原分类/榜单/慢滴流验证，独立 Java 8 javac/JUnit 合计 25/25 通过；Android 顶部新增信息行、卡片文字行数与遥控器实际显示仍待统一设备验证。

匿名元数据客户端另按 A 模块公共网络边界统一为全新 OkHttp Builder、系统 TLS、PublicNetworkPolicy 公共 DNS 和 NO_PROXY，不继承旧全局 Client 的 hosts、代理或 TLS；每跳仍执行公共目标准入和同 host/禁止降级校验。

## 待统一验证

全量编译及资源接线；遥控器十项导航、四地区四类型、返回和焦点；来源故障/慢响应的真实取消；各地区×类型覆盖样本；榜单在线取数与错误缓存；统一搜索使用 expected_year/type/area 的版本核对；历史详情续播；真机字体、卡片尺寸及北京时间显示。没有将这些项目标为通过。
