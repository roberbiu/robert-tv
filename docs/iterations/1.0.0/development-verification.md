## 已发现并修订的集成边界

以下是代码修订及静态审查结果，仍需最终候选的交互和账号验证：

1. 元数据请求不再错误地构造播放代际0；取消及陈旧的播放结果必须回收未交付租约。
2. 自动详情预览和自动字幕替代不得强弹扫码；明确播放动作才允许授权或真实文件准备。等待授权、取消和目录占位项不计观看历史。
3. 云盘续播核对最新分享身份并按文件ID恢复，使用最新提取码；清晰度和排序变化不改变进度键。
4. 原画权益不足保留切回自动均衡的入口，与登录失效区分；错误的安全中文信息不再被空URL泛错覆盖。
5. 旧播放引用和字幕回滚保护分开；恢复先消费旧目标标记，再取得活动引用，随后释放保护。暂停取消超时/解析/授权任务；用户明确重新打开播放器才解除界面暂停门禁。
6. 云盘文件选择将实际页码写入公开文件引用，避免第二页被误记为第一页。
7. 公网地址限制由元数据和云盘网络共同使用，恢复仅在系统DNS失败、超时或结果不合规时触发；固定HTTPS解析器、系统TLS、公网答案校验及有界预算不改变全局DNS、手机LAN配对或本机媒体监听。独立审校见 [DNS恢复审校](network-recovery-review.md)，最终Release及不同API版本仍需实测。

云盘与代理模块的独立静态审校见 [代码审校记录](cloud-code-review.md)。测试夹具、公开元数据、编译、代码审校均不能证明真实账号、媒体和电视上的完整功能。
