## 已确认验收基准

- 固定20部片单，至少16部有身份正确的版本候选；匹配不能冒充实播，保留失败记录。
- 同片单至少12部实播，每部观察至少3分钟，覆盖确认稿要求的类别、地区和体验检查。
- 主力玩偶线路连续播放至少60分钟。
- 会话跨日观察至少24小时；有效时复用、真实失效时验证恢复，不承诺平台保证24小时有效，72小时为加强观察建议。
- 至少雷鸟鹤6 Ultra真机；建议补充不同型号Android TV/盒子。设备不足时按确认稿带有限支持范围方案回用户，不能宣传全机型兼容。
- 新安装、同签名升级、字幕与替代、共存故障、独立账号、最终APK与交付记录按确认稿分别验收。
