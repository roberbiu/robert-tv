# Robert影视安装与使用

当前交付版本为 **0.1.0-preview.2 预览版**。目标设备是雷鸟鹤 6 Ultra，实际安装、遥控和播放效果仍需在你的电视上验证。

## 安装前准备

- 电视能够正常连接互联网。
- 获取本次交付提供的 Robert影视 APK 文件，将它复制到 U 盘。
- 本包同时包含 ARM 32 位和 64 位支持，只需安装这一个 APK。

正常安装和使用不需要 ADB、Root、GitHub 登录，也不需要导入源、填写接口或配置字幕凭据。默认来源不要求夸克、UC 网盘账号。

## 通过 U 盘安装

1. 将存有 APK 的 U 盘插入电视 USB 接口。
2. 使用电视自带或已有的文件管理器找到 U 盘中的 APK，选择打开。
3. 如果系统询问是否允许该文件管理器安装应用，按系统提示允许本次安装。
4. 按提示完成安装，然后从电视应用列表打开 **Robert影视**。

不同年款和固件的菜单名称可能不同，以电视实际提示为准。如果电视找不到 U 盘或没有提供 APK 安装入口，请反馈当前页面和系统版本，再根据实际情况确定安装方式。

## 首次观看

1. 打开应用，首页默认显示“最近观看”；首次没有记录时显示“暂无观看记录”。
2. 使用“去搜索”搜索片名，也可以用顶部分类浏览内容。
3. 进入影片详情，确认影片年份、季集及版本，再开始播放。
4. 如果某个版本无法播放，可以返回详情尝试其他版本；无需重新寻找或导入接口。

默认目录包含量子、非凡、暴风三个普通点播来源。来源可用性会变化，搜索结果不代表一定能够播放。目录数据会自动检查更新，并在下一次正常启动、加载默认内容时使用，不会为了更新目录打断正在观看的内容。

观看后返回首页会刷新最近记录，并显示上次观看的集数。点击记录沿用既有续播逻辑。升级到本版首次启动会把首页切换为最近观看；之后如在设置中主动切换首页内容，再次启动会保留你的选择。搜索框保留普通输入法、屏幕字母键盘和遥控器搜索，不需要触控笔。

清晰度、字幕和授权信息以应用可确认的状态为准。“来源标注中文”和“检测到中文轨”不是同一回事；“未知”也不代表一定没有字幕。若没有可用中文字幕，可以尝试其他版本；最终仍没有时允许继续播放。

## 当前版本范围

- 优先提供在线点播；直播入口暂未开放。
- 专用夸克、UC 网盘接入尚不属于本包已验证交付的能力。
- 不包含已验收的机器翻译字幕功能。
- 不保证所有影片都有、所有版本都带中文字幕，或所有来源始终可用。

本地已完成构建与部分模拟器验证，但模拟器效果不能代替雷鸟真机验收。具体验证范围见[本次验证](validation-2026-10-29.md)和[首版验证](validation-2026-10-28.md)。

## 后续升级

后续会提供使用同一项目签名、递增版本号的安装包。取得新 APK 后，按系统提示覆盖安装；正常使用仍不需要重新导入来源。

如果系统提示安装失败或签名不一致，先保留错误原文并反馈，不需要先卸载现有版本。安装与升级的具体处理以实际错误为依据。

## 如何反馈问题

请在本次对话中提供：

- 应用版本、电视型号和系统版本。
- 安装或播放时的错误原文，以及出现问题的操作步骤。
- 涉及影片时，补充片名、年份、季和集数，以及所选版本。
- 必要时提供已遮挡个人信息的截图。

不需要提供 Cookie、token、网盘密码、签名密钥或带私人凭据的播放地址。
