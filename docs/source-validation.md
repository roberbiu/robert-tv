# 来源验证记录与开发探测工具

本记录日期：**2026-10-28**。用于开发维护，不要求 Robert影视使用者运行工具、配置接口或提供字幕 token。

## 本轮只读验证结论

候选入口来自 [TVboxorg 聚合目录](https://github.com/TVboxorg/TVbox/blob/main/dist/official.json)。只访问普通 CMS JSON API 和 HLS 文本清单，没有执行 JAR、JavaScript 或 Python 来源适配器，没有下载影片分片，也没有解码实播。

| 技术候选 | API 入口 | 搜索／详情 | HLS 清单层证据 |
| --- | --- | --- | --- |
| 量子 | `https://lzizy1.com/api.php/provide/vod/` | 六组测试关键词有结果，详情含年份、分类与播放分组 | 《老友记 第一季》1994、第 01 集：主／子清单返回成功，确认 `#EXTM3U` 和分片条目 |
| 非凡 | `http://ffzy5.tv/api.php/provide/vod/` | 六组测试关键词有结果，标准 CMS 详情结构 | 《老友记第一季》1994、第 01 集：主／子清单返回成功，确认分片条目 |
| 暴风 | `https://bfzyapi.com/api.php/provide/vod` | 六组测试关键词有结果，部分 ID 为字符串并含额外字段 | 《老友记第一季》1994、第 01 集：媒体清单返回成功，确认分片条目 |

六组测试关键词是“西游记、流浪地球、老友记、熊出没、舌尖上的中国、国家宝藏”。它们用于检查元数据结构与匹配风险，**搜索命中不等于片单验收通过**。

上述入口仅为技术候选，不表示内容授权、字幕、画质、持续播放、账号持续性或雷鸟真机已经验收。

## 四类需要区分的问题

1. **HTTP 接入拒绝**：本次索尼列表接口可读，但六次搜索返回 403；没有尝试绕过。
2. **TLS／网络失败**：本次如意接口 TLS 连接失败；没有关闭证书校验。
3. **元数据匹配失败**：同名“国家宝藏”可能是美国电影或国产综艺；“流浪地球”的首条候选可能是短剧或纪录片。标题空格、年份和季集也可能不同，不能取第一项就认定是同一作品。
4. **字幕证据不足**：测试详情没有可靠的独立字幕 URL／字幕语言字段，清单未声明字幕分轨；这不证明没有硬字幕或流内字幕，也不能宣称已经有中文字幕。

前三项包含已观察到的接入或匹配问题；第四项是未确认状态，不应伪装成已检测“没有字幕”。工具另会记录超时、JSON／CMS 结构错误、清单不符及预算耗尽等分类；不能把未发生的分类写成该来源已发生的故障。

`vod_lang` 是内容语言信息，`vod_sub` 是 CMS 副标题字段，均不能当作中文字幕证据。`HD中字` 等备注只能标为“来源标注中文”，不能标成“检测确认”。

量子／非凡分类中出现“伦理片”，暴风分类中出现“理论片”；需要在分类、首页和搜索结果中落实内容类别白名单，不能仅隐藏分类入口。

探测工具也拒绝含“福利”的分类，与应用的默认内容过滤规则一致；这是防护规则，不表示本轮在三个候选的分类表中已观察到该名称。

## 接口说明与复用条件

[非凡帮助中心](https://ffzy5.tv/help/)公开了 XML 和 JSON 列表／详情接口及 CMS 技术接入说明。其[首页](https://ffzy5.tv/)同时说明内容来自互联网并提供投诉撤除机制。本轮没有找到覆盖全部影视内容的权利人授权文件，其他候选的内容授权也未核实。

公开提供 API 可以作为技术接入证据，不能自动认定为已经核实影视内容授权。目录维护频繁、HTTP 成功及 HLS 清单合法，也都不能替代实际播放验证。

## 可复现工具

`tools/probe_sources.py` 仅使用 Python 标准库，默认读取工程内 `sources/catalog.json`，只选择可搜索的 `type: 1` 来源。默认最多 3 个来源、6 个样例、48 次请求尝试、90 秒全局预算；每次网络超时默认 8 秒。重定向同样计入请求预算，跳转仍须是 HTTP／HTTPS，URL 不能携带用户名和密码。TLS 校验保持开启，不接收 Cookie 或授权头。

来源或清单中的中文路径／查询会先规范为 UTF-8 百分号编码；已有 `%xx` 转义、查询分隔符和加号保持原义，不重复编码。国际化域名按 IDNA 处理，IPv6 使用合法括号形式。首次请求、重定向和子清单都使用规范后的地址；无效 URL、编码及网络异常转为脱敏错误分类，不让单个来源故障中断其他已收集的证据。

先做无网络自检：

```powershell
python "tools/probe_sources.py" --self-test
```

新增工具本次已通过离线自检，覆盖标题空格／季名／年份归一、同名不同年份及不同季拒绝、错误字幕字段不误判、来源中文声明分级、非 HTTP／带身份 URL 拒绝、请求预算及输出脱敏。还覆盖中文 URL、IDNA／IPv6、已有转义不双重编码、重定向使用规范地址、编码／网络错误分类，以及前一用例已取得元数据后 HLS 或后续用例网络失败仍可序列化保留证据；自检网络请求数为 0。本节上方的来源记录来自本轮受限手动探测，并不表示新增工具已完成公网全量回归。

按需运行少量元数据探测，输出位置由开发者指定：

```powershell
python "tools/probe_sources.py" --output "work/source-probe.json"
```

只有明确添加 `--hls` 时才探测 HLS；每个来源最多选择一个匹配版本，只读取主清单和至多一个子清单，各最多 16 KiB。不会请求影片分片、密钥或字幕文件，不执行脚本。清单取样可能截断，证据中会标记，不能视为完整 HLS 校验。

```powershell
python "tools/probe_sources.py" --hls --max-requests 20 --max-seconds 60 --output "work/source-probe-hls.json"
```

维护者可用 `--cases-file` 指定一个最多 6 项的 JSON 数组。每项必须有 `title`，可指定整数 `year`、`season`、`episode`，以及 `query` 和 `category`。例如：

```json
[
  {
    "title": "老友记第一季",
    "query": "老友记",
    "year": 1994,
    "season": 1,
    "episode": 1,
    "category": "美剧"
  }
]
```

只查搜索第一页；先比较规范化标题，再取少量候选详情核对年份与季。集号在可选 HLS 选择中核对。没有足够元数据时保留未确认状态，不擅自推断；需要继续分页的匹配不能由本工具的首屏结果否定。

输出仅保存来源 key、样例及匹配元数据、清单结构摘要、耗时、错误分类和明确的“未实播”状态。不会保存 API 或播放 URL、清单 URI、请求查询参数、密钥、Cookie、token 或个人历史。影片语言、副标题和备注文本不作为字幕确认依据；明确“中字”备注仅转为来源声明枚举。

网络失败属于证据数据，正常生成报告后退出码为 0，不表示所有来源通过。输入无效退出码为 2；自检断言失败退出码非 0。开发者应检查报告中的各项错误和限制，不能仅用进程退出码作为来源验收结论。

## 后续真实验收门槛

- 在应用播放器中验证真实起播、画面、声音、持续播放和跳转。
- 对固定代表片单记录实际分母、匹配影片／年份／季集、起播、中文字幕及授权要求。
- 对字幕标明检测确认、来源标注或未知；硬字幕需要画面证据，流内字幕需要播放器轨道证据。
- 验证来源不可用、超时及错误配置时的替代和回退行为。
- 最终在用户的雷鸟鹤 6 Ultra 上验证遥控焦点、硬件解码与升级兼容。
