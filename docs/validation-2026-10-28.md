## 来源技术探测

默认来源为量子、非凡、暴风三个普通 type 1 CMS。它们在当前目录中标为不要求网盘账号授权，此标记不代表永久可播或字幕完整。

- 三个来源、两个样例，共六组元数据匹配检查。
- 三条 HLS 路径的主清单和子清单可读。
- 本轮探测共 17 次请求。

这些检查属于元数据与播放清单探测，不是六组影片全部实播，也不能证明所有分片、声画、解码或中文字幕均正常。

## 目录更新与执行边界

- APK 内置初始目录，使用时不要求用户填写来源地址。
- 受控目录只描述普通 CMS 数据接口；不通过目录更新自动引入陌生 JAR、JS 或 Python 执行代码。
- 缓存与内置目录均有效时选择较高 version，同版本优先内置目录。
- 远端目录只有严格更高的 version 才可替换当前有效版本。每次维护内容变化均需递增 version。
- 更新数据写入本地缓存，在下一次正常启动、加载默认内容时生效，不在后台并发替换正在使用的来源映射。
- 网络或校验失败时保留本机有效目录；不以目录可读或 HTTP 成功冒充实际播放成功。

以上为当前实现和策略验证范围，不将原上游客户端整体描述为执行沙箱。
